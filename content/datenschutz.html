Was beim Aufruf passiert

Wenn Sie eine Seite aufrufen, schickt Ihr Browser dem Server Ihre IP-Adresse, die aufgerufene Adresse und übliche technische Angaben wie Browsertyp und Sprache. Der Server braucht diese Angaben, um Ihnen die Seite verschlüsselt (HTTPS) zu schicken. Rechtsgrundlage ist mein berechtigtes Interesse, die Website bereitzustellen (Art. 6 Abs. 1 lit. f DSGVO).

Der Server speichert davon nichts: Er führt kein Zugriffsprotokoll und schreibt keine IP-Adressen in Fehlerprotokolle. Sobald die Seite ausgeliefert ist, sind die Angaben auf dem Server weg.

Die Website liegt auf einem gemieteten Server der netcup GmbH (Karlsruhe) in einem Rechenzentrum in Deutschland. Die Adresse irlcommons.org wird über Cloudflare aufgelöst (nur DNS); die Verbindung zur Website selbst läuft nicht über Cloudflare.

Keine Cookies, kein Tracking

Diese Website setzt keine Cookies und zählt oder verfolgt keine Besucher. Sie bindet nichts von anderen Websites ein. Die Schriften (Atkinson Hyperlegible Next und IBM Plex Mono) liegen auf demselben Server; Ihr Browser lädt nichts von Google oder anderen Anbietern.

Ihr Browser speichert Dateien im Zwischenspeicher. Für einen Tag speichert er, dass er die Seite nur verschlüsselt aufrufen soll (HSTS). Außerdem speichert er ein von Ihnen gewähltes Farbschema, bis Sie die Daten dieser Website löschen. Die Schaltfläche für das Farbschema wechselt zwischen dunkel und hell. Der Beta-Hinweis speichert keine Daten.

Links zu anderen Websites

Diese Website verlinkt auf GitHub und auf die Projekte und Dienste, die sie nennt. Diese Seiten werden erst geladen, wenn Sie einen Link anklicken, und Ihr Browser teilt ihnen nicht mit, von welcher Seite Sie kommen. Danach gilt die Datenschutzerklärung der jeweiligen Website.

GitHub, über das die Mitarbeit läuft, betreibt die GitHub, Inc. in den USA mit eigenen Regeln: Datenschutzerklärung von GitHub.

Die Website verlinkt außerdem auf den Discord-Server des Projekts. Von Discord wird erst etwas geladen, wenn Sie den Link anklicken. Auf Discord gilt die Datenschutzerklärung von Discord.

Wenn Sie mir schreiben

E-Mails an hello@irlcommons.org laufen über Email Routing von Cloudflare, das sie an mein Postfach weiterleitet. Cloudflare verarbeitet die Nachricht, um sie zuzustellen, und bewahrt sie nicht in einem Postfach auf. Laut seiner Dokumentation speichert Cloudflare die weitergeleiteten E-Mails nicht und greift nicht auf sie zu. Cloudflare führt aber zu jeder Nachricht einen Eintrag in einem Aktivitätsprotokoll, das ich in meinem Cloudflare-Konto sehe: Absender, Empfänger, Betreff, Zeitpunkt und ob sie weitergeleitet wurde.

Wenn Sie mir eine E-Mail schreiben oder mich anrufen, nutze ich Ihre Angaben nur, um zu antworten, und lösche sie, wenn sie dafür nicht mehr nötig sind (Art. 6 Abs. 1 lit. f DSGVO). Was Sie auf GitHub schreiben, ist dort nach den Regeln von GitHub sichtbar.
