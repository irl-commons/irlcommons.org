irl-commons

The data lives in a public repository. Anyone can reuse it with credit, under CC BY 4.0, and anyone can help improve it.

  • Each list comes with a JSON Schema and a validator. The code that checks the data is under the MIT licence.
  • It's an early version, made by hand, and a lot is still missing.
